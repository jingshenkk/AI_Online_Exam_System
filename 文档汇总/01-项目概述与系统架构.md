# 项目概述与系统架构

## 1. 项目简介

本项目为**基于 LLM 的在线考试系统**，旨在解决传统在线考试系统无法对主观题进行自动评分的痛点。系统通过集成大语言模型（LLM），实现了对主观题答案的智能评分，同时提供完整的试题管理、试卷管理、考试管理和成绩管理功能，适用于高校、培训机构等教育场景。

### 1.1 项目背景

随着在线教育的普及，传统在线考试系统在主观题评分方面存在明显局限：人工批改效率低、评分标准不统一。本系统引入 LLM 技术，通过"评分细则 + 多模型投票"机制，实现主观题的自动化、标准化评分，显著提升阅卷效率和公平性。

### 1.2 项目特色

- **LLM 智能评分**：支持宽松（单模型）和严格（三模型投票）两种评分模式
- **逐点评分机制**：基于预设评分细则，对每个得分点独立评判
- **AI 辅助出题**：LLM 自动生成主观题评分细则，教师审核后即可使用
- **完整考试闭环**：覆盖从出题、组卷、发布考试到成绩导出的全流程
- **多角色权限**：支持管理员、教师、学生三种角色，权限独立管理

## 4. 核心业务流程

### 4.1 用户认证流程

```
用户输入账号密码
       │
       ▼
  前端发送登录请求
       │
       ▼
  后端验证账号密码
       │
  ┌────┴────┐
  │ 验证成功 │
  └────┬────┘
       │
  返回 JWT Token（access + refresh）
       │
       ▼
  前端存储 Token（Cookie/localStorage）
       │
       ▼
  后续请求携带 Authorization: Bearer <token>
       │
       ▼
  后端 JWT 中间件验证 Token 有效性
```

### 4.2 在线考试流程

```
学生登录系统
     │
     ▼
查看待参加考试列表（/examOnline）
     │
     ▼
进入考试引导页（确认考试信息）
     │
     ▼
开始答题（系统记录开始时间）
     │
     ├── 客观题（选择/判断）→ 前端实时保存草稿
     │
     └── 主观题（简答/论述）→ 前端实时保存草稿
     │
     ▼
提交答卷
     │
     ▼
后端自动评分
     │
     ├── 客观题 → 直接比对答案，计算得分
     │
     └── 主观题 → 触发 LLM 评分服务
              │
              ├── LENIENT 模式：单 LLM 评分
              │
              └── STRICT 模式：三 LLM 独立评分 → 投票取最终结果
     │
     ▼
生成考试结果（ExamResult + ExamResultDetail）
     │
     ▼
学生查看成绩 / 教师查看成绩单 / 导出 Excel
```

### 4.3 LLM 主观题评分流程

```
学生提交主观题答案
        │
        ▼
创建 AnswerRecord（状态: PENDING）
        │
        ▼
获取该题目的评分细则（ScoringPoint 列表）
        │
        ▼
对每个评分细则逐点评判
        │
        ├── LENIENT 模式（宽松）
        │       │
        │       └── 调用 LLM-1 判断是否命中该得分点
        │
        └── STRICT 模式（严格）
                │
                ├── 并发调用 LLM-1、LLM-2、LLM-3
                │
                └── 三模型投票，多数决定最终结果
        │
        ▼
汇总各得分点分数 → 计算总分
        │
        ▼
更新 AnswerRecord（状态: SCORED，final_score）
        │
        ▼
教师可手动调整分数（adjustScore）
```

### 4.4 试卷组卷流程

```
教师创建试卷（Paper）
      │
      ▼
添加试卷模块（PaperModule，最多 4 个）
      │
      ▼
从题库选题关联到试卷（PaperQuestions）
      │
      ├── 手动选题（从个人题库/公共题库）
      │
      └── 随机选题（指定题型和数量）
      │
      ▼
设置每题分值和顺序
      │
      ▼
发布试卷（is_published = True）
      │
      ▼
创建考试并绑定试卷（Exam）
      │
      ▼
关联参考学生
      │
      ▼
发布考试（is_published = True）
```

## 6. 安全设计

### 6.1 身份认证
- 采用 **JWT（JSON Web Token）** 无状态认证方案
- Access Token 有效期 **7 天**，Refresh Token 有效期 **14 天**
- 所有 API 请求（除登录外）均需携带有效 Token

### 6.2 跨域处理
- 使用 `django-cors-headers` 配置允许的跨域来源
- 生产环境应限制为前端域名白名单

### 6.3 数据安全
- 敏感配置（数据库密码、LLM API Key）通过 `.env` 文件管理，不提交至版本控制
- 软删除机制：重要数据（用户、试题、试卷、考试）均采用 `is_deleted` 标记删除，不物理删除

## 7. 项目约束与规范

| 约束项 | 说明 |
|--------|------|
| 分页大小 | 默认每页 50 条 |
| 试卷模块数 | 最多 4 个模块 |
| 考试时间 | 不可跨天，时间步长 10 分钟 |
| 主观题字数 | 默认上限 1000 字 |
| 试卷发布条件 | 必须关联至少一道试题 |
| 考试删除限制 | 已发布的考试不可删除 |
| 考试编辑限制 | 已开始的考试不可编辑 |
| 成绩单存储 | 导出文件存储在 `ExamResultFiles/` 目录 |
