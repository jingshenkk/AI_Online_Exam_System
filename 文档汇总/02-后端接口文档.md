# 后端接口文档

## 说明

- **Base URL**: `http://localhost:8000/api`
- **认证方式**: JWT Bearer Token
- **请求头**: `Authorization: Bearer <access_token>`
- **响应格式**: JSON
- **时间格式**: ISO 8601（`YYYY-MM-DDTHH:mm:ss`）

### 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

### 错误响应格式

```json
{
  "code": 400,
  "message": "错误描述",
  "data": null
}
```

## 一、用户认证模块

### 1.1 学生登录

- **URL**: `POST /api/studentLogin`
- **认证**: 无需认证
- **描述**: 学生账号登录，返回 JWT Token

**请求体**

```json
{
  "username": "student001",
  "password": "123456"
}
```

**响应示例**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "userId": "uuid-xxxx",
    "name": "张三",
    "role": "student",
    "refresh": "eyJ...",
    "access": "eyJ..."
  }
}
```

---

### 1.2 教师/管理员登录

- **URL**: `POST /api/teacherLogin`
- **认证**: 无需认证
- **描述**: 教师或管理员账号登录

**请求体**

```json
{
  "username": "teacher001",
  "password": "123456",
  "isAdmin": false
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | string | 是 | 用户名 |
| password | string | 是 | 密码 |
| isAdmin | boolean | 否 | 是否以管理员身份登录，默认 false |

**响应示例**

```json
{
  "code": 200,
  "data": {
    "userId": "uuid-xxxx",
    "name": "李老师",
    "role": "teacher",
    "refresh": "eyJ...",
    "access": "eyJ..."
  }
}
```

---

### 1.3 修改学生密码

**请求体**

## 三、试题管理模块

**查询参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| topic | string | 否 | 题目内容（模糊查询） |
| type | string | 否 | 题型（select/judge/essay） |
| trial_type | string | 否 | 题库类型（public/private） |
| status | boolean | 否 | 题目状态 |
| is_deleted | boolean | 否 | 是否已删除 |
| created_user | string | 否 | 创建人 ID |
| collector | string | 否 | 收藏者 ID（查询收藏题目） |
| pageSize | int | 否 | 每页条数 |

  "code": 200,

    "list": [
      {

        "topic": "以下哪个是 Python 的关键字？",
        "options": "[\"A. class\", \"B. define\", \"C. function\", \"D. method\"]",
        "answer": "A",
        "type": "select",
        "trial_type": "private",
        "status": true,
        "grading_mode": "LENIENT",

### 3.2 创建试题

- **URL**: `POST /api/question`
- **认证**: 需要 JWT Token

**请求体**

```json
{
  "topic": "简述 RESTful API 的设计原则",
  "options": "",
  "answer": "RESTful API 的设计原则包括：无状态、统一接口、资源导向...",
  "type": "essay",
  "trial_type": "private",
  "grading_mode": "STRICT",
  "max_chars": 500,
  "status": true,
  "created_user": "uuid-teacher"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| topic | string | 是 | 题目内容 |
| options | string | 否 | 选项（选择题必填，JSON 字符串） |
| answer | string | 是 | 参考答案 |
| type | string | 是 | 题型：select（选择）/ judge（判断）/ essay（主观） |
| trial_type | string | 是 | 题库类型：public（公共）/ private（私有） |
| grading_mode | string | 否 | 评分模式：LENIENT（宽松）/ STRICT（严格），主观题有效 |
| max_chars | int | 否 | 主观题字数上限，默认 1000 |
| status | boolean | 否 | 题目状态，默认 true |
| created_user | string | 是 | 创建人 ID |

## 附录：枚举值说明

| 字段 | 枚举值 | 说明 |
|------|--------|------|
| role | student / teacher / admin | 用户角色 |
| gender | male / female | 性别 |
| type（试题） | select / judge / essay | 题型：选择题 / 判断题 / 主观题 |
| trial_type | public / private | 题库类型：公共 / 私有 |
| grading_mode | LENIENT / STRICT | 评分模式：宽松（单模型）/ 严格（三模型投票） |
| status（答题记录） | PENDING / SCORING / SCORED | 评分状态：待评分 / 评分中 / 已评分 |
| hit（评分点命中） | FULL / MISS | 命中状态：完全命中 / 未命中 |
| is_show（菜单） | ALL / Teacher / Student / Admin | 菜单显示角色 |
