# 数据库设计文档

## 说明

- **数据库类型**: MySQL 8.2
- **数据库名称**: `exam_online`
- **字符集**: utf8mb4
- **主键规则**: 所有表主键均使用 UUID（字符串类型）
- **软删除**: 重要业务表均设有 `is_deleted` 字段，删除操作为逻辑删除

---

## 一、数据库 ER 图（文字描述）

```
User（用户）
  ├── Student（学生）  ──── ExamResult（考试结果）
  │                              ├── ExamResultDetail（结果详情）
  │                              ├── AnswerRecord（答题记录）
  │                              │       └── ScorePointDetail（逐点评分明细）
  │                              └── AnswerDraft（答案草稿）
  └── Teacher（教师）
          ├── Questions（试题）
          │       ├── ScoringPoint（评分细则）
          │       └── QuestionsFavorite（试题收藏）
          ├── Paper（试卷）
          │       ├── PaperModule（试卷模块）
          │       └── PaperQuestions（试卷-试题关联）
          └── Exam（考试）
                  └── ExamResult（考试结果）
```

## 四、核心业务数据流

### 4.1 学生参加考试的数据流

```
1. 教师创建考试 → exam 表新增记录
2. 教师关联学生 → exam_result 表批量新增记录（result_mark 为 NULL）
3. 学生开始答题 → exam_result.start_time 更新
4. 学生保存草稿 → answer_draft 表 upsert
5. 学生提交答卷 → exam_result_detail 表批量新增（每题一条）
6. 客观题自动评分 → 直接计算 mark 写入 exam_result_detail
7. 主观题触发 LLM → answer_record 新增（PENDING）
8. LLM 逐点评分 → score_point_detail 批量新增
9. 汇总得分 → answer_record.final_score 更新（SCORED）
10. 更新总分 → exam_result.result_mark 更新
```

### 4.2 LLM 评分数据流（STRICT 模式）

```
answer_record（PENDING）
    │
    ├── 获取 scoring_point 列表（该题所有评分细则）
    │
    └── 对每个 scoring_point 并发调用 3 个 LLM
            │
            ├── LLM-1 → llm_1_hit / llm_1_score / llm_1_reason
            ├── LLM-2 → llm_2_hit / llm_2_score / llm_2_reason
            └── LLM-3 → llm_3_hit / llm_3_score / llm_3_reason
            │
            └── 投票（vote_count >= 2 则命中）→ final_hit / final_score
            │
            写入 score_point_detail
    │
    汇总所有 score_point_detail.final_score
    │
    更新 answer_record.final_score（SCORED）
```
