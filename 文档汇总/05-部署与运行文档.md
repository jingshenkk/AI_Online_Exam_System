## 二、后端部署

### 2.1 克隆项目

```bash
git clone <仓库地址>
cd AI-Exam-Server
```

### 2.2 创建虚拟环境

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境（macOS/Linux）
source venv/bin/activate

# 激活虚拟环境（Windows）
venv\Scripts\activate
```

### 2.3 安装依赖

```bash
pip install -r requirements.txt
```

**主要依赖说明**:

```
Django==4.2.8
djangorestframework==3.14.0
djangorestframework-simplejwt==5.3.1
django-cors-headers==4.3.1
mysqlclient==2.1.0
pandas==2.0.3
openpyxl==3.1.2
langchain>=0.1.0
langchain-openai>=0.0.5
python-dotenv>=1.0.0
```

### 2.4 配置环境变量

在 `AI-Exam-Server/` 目录下创建 `.env` 文件：

```env
# LLM 配置
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# 数据库配置（如需覆盖 settings.py 中的默认值）
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=exam_online
DB_USER=root
DB_PASSWORD=your_db_password
```

> **注意**: `.env` 文件已加入 `.gitignore`，不会提交到版本控制，请妥善保管 API Key。

### 2.5 配置数据库

#### 2.5.1 创建数据库

```sql
-- 登录 MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE exam_online CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 退出
EXIT;
```

#### 2.5.2 修改数据库配置

编辑 `ExamOnline/settings.py`，确认数据库配置正确：

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.mysql',
        'NAME': 'exam_online',
        'USER': 'root',
        'PASSWORD': '你的数据库密码',
        'HOST': '127.0.0.1',
        'PORT': '3306',
        'TIME_ZONE': 'Asia/Shanghai'
    }
}
```

### 2.6 数据库迁移

```bash
cd AI-Exam-Server

# 生成迁移文件
python manage.py makemigrations

# 执行迁移
python manage.py migrate
```

### 2.7 导入初始数据

```bash
# 导入菜单等初始数据
python manage.py loaddata initial_data.json
```

### 2.8 创建超级管理员（可选）

```bash
python manage.py createsuperuser
```

### 2.9 启动后端服务

```bash
# 开发模式启动（默认端口 8000）
python manage.py runserver

# 指定端口启动
python manage.py runserver 0.0.0.0:8000
```

启动成功后，后端服务运行在 `http://localhost:8000`

### 2.10 验证后端运行

```bash
# 测试登录接口
curl -X POST http://localhost:8000/api/teacherLogin \
  -H "Content-Type: application/json" \
  -d '{"username": "admin", "password": "123456"}'
```

## 三、前端部署

### 3.1 进入前端目录

```bash
cd ExamOnline-Front
```

### 3.2 安装依赖

```bash
# 使用 pnpm（推荐）
pnpm install

# 或使用 npm
npm install
```

### 3.3 配置环境变量

在 `ExamOnline-Front/` 目录下检查 `.env` 文件：


```bash
# 或
npm run dev
```

启动成功后，前端服务运行在 `http://localhost:5173`

```bash
pnpm build

# 或
npm run build
```

构建产物在 `dist/` 目录下，可部署到 Nginx 等 Web 服务器。

## 五、常见问题排查

### 5.1 后端启动失败

**问题**: `django.db.utils.OperationalError: (2003, "Can't connect to MySQL server")`

**解决**:
1. 确认 MySQL 服务已启动：`mysql.server start`（macOS）
2. 确认数据库配置（HOST、PORT、USER、PASSWORD）正确
3. 确认数据库 `exam_online` 已创建

---

**问题**: `ModuleNotFoundError: No module named 'xxx'`

**解决**:
```bash
# 确认虚拟环境已激活
source venv/bin/activate

# 重新安装依赖
pip install -r requirements.txt
```

---

**问题**: `mysqlclient` 安装失败（macOS）

**解决**:
```bash
# 安装 MySQL 客户端库
brew install mysql-client

# 设置环境变量后重新安装
export PKG_CONFIG_PATH="/usr/local/opt/mysql-client/lib/pkgconfig"
pip install mysqlclient
```

---

### 5.2 前端启动失败

**问题**: `Error: Cannot find module 'xxx'`

**解决**:
```bash
# 删除 node_modules 重新安装
rm -rf node_modules
pnpm install
```

---

**问题**: 前端请求报 CORS 跨域错误

**解决**:
1. 确认后端 `settings.py` 中 `CORS_ALLOWED_ORIGINS` 包含前端地址
2. 确认前端 `.env` 中 `VITE_API_BASE_URL` 配置正确

---

**问题**: 登录后 API 请求返回 401

**解决**:
1. 检查 Cookie 中是否存有 `access_token`
2. Token 可能已过期（有效期 7 天），重新登录即可

---

### 5.3 LLM 评分不生效

**问题**: 主观题提交后一直处于 `PENDING` 状态

**解决**:
1. 检查 `.env` 中 `OPENAI_API_KEY` 是否正确配置
2. 检查 `OPENAI_BASE_URL` 是否可访问（如使用代理需确认代理地址）
3. 查看后端日志确认 LLM 调用是否报错：
   ```bash
   python manage.py runserver 2>&1 | grep -i "error\|llm\|grading"
   ```

---

**问题**: 主观题没有评分细则，LLM 无法评分

**解决**:
1. 进入"个人题库"→ 找到对应主观题 → 点击"评分细则"
2. 手动添加评分细则，或点击"AI 生成"让 LLM 自动生成
3. 审核通过评分细则后，该题才能参与 LLM 评分

## 六、生产环境部署建议

### 6.1 后端生产部署（Gunicorn + Nginx）

```bash
# 安装 Gunicorn
pip install gunicorn

# 启动 Gunicorn（4 个 worker 进程）
gunicorn ExamOnline.wsgi:application \
  --workers 4 \
  --bind 0.0.0.0:8000 \
  --timeout 120 \
  --daemon
```

**Nginx 配置示例**:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/ExamOnline-Front/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 成绩单文件下载
    location /ExamResultFiles/ {
        alias /path/to/AI-Exam-Server/ExamResultFiles/;
    }
}
```

### 6.2 生产环境安全配置

在 `settings.py` 中修改以下配置：

```python
# 关闭调试模式
DEBUG = False

# 配置允许的主机
ALLOWED_HOSTS = ['your-domain.com', 'www.your-domain.com']

# 配置允许的跨域来源
CORS_ALLOWED_ORIGINS = [
    'https://your-domain.com',
]

# 使用更安全的 SECRET_KEY（从环境变量读取）
SECRET_KEY = os.environ.get('DJANGO_SECRET_KEY')
```

### 6.3 数据库备份建议

```bash
# 定期备份数据库
mysqldump -u root -p exam_online > backup_$(date +%Y%m%d).sql

# 恢复数据库
mysql -u root -p exam_online < backup_20240101.sql
```

## 七、开发规范

### 7.1 后端开发规范

- 新增 API 接口需在对应 App 的 `views.py` 中实现，并在 `urls.py` 中注册路由
- 所有接口返回统一使用 `response_utils` 中的响应格式
- 数据模型变更后需执行 `makemigrations` 和 `migrate`
- 敏感配置统一放在 `.env` 文件中，通过 `python-dotenv` 读取

### 7.2 前端开发规范

- 新增 API 调用在 `src/api/` 对应模块文件中添加
- 页面组件放在 `src/views/` 对应模块目录下
- 新增路由在 `src/router/index.ts` 中注册
- 全局状态使用 Pinia Store 管理，按功能模块创建独立 Store 文件
