### 2.2 路由守卫

```typescript
// router/index.ts 路由守卫逻辑
router.beforeEach((to, from, next) => {
  // 1. 未登录用户跳转到登录页
  if (!token && to.path !== '/login') {
    next('/login')
    return
  }
  // 2. 已登录用户访问登录页，跳转到首页
  if (token && to.path === '/login') {
    next('/homepage')
    return
  }
  next()
})
```

## 三、页面详细说明

### 3.1 登录页（Login）

**路径**: `/login`  
**文件**: `src/views/Login/index.vue`

**功能描述**:
- 支持学生、教师、管理员三种角色登录（Tab 切换）
- 记住密码功能（Cookie 持久化）
- 登录成功后存储 JWT Token 和用户信息，跳转首页

**页面元素**:
- 角色切换 Tab（学生 / 教师 / 管理员）
- 用户名输入框
- 密码输入框
- 记住密码复选框
- 登录按钮

**交互逻辑**:
```
用户输入账号密码 → 点击登录
  → 调用 studentLogin / teacherLogin API
  → 成功：存储 token + userId + name + role 到 Cookie
  → 跳转 /homepage
  → 失败：显示错误提示
```

### 3.3 个人题库（PersonalWarehouse）

**路径**: `/personalWarehouse`  
**文件**: `src/views/QuestionManagement/PersonalWarehouse.vue`

**功能描述**:

**新增/编辑试题表单字段**:

### 3.5 评分细则管理（ScoringPointManagement）

**路径**: `/scoringPoints/:id`（id 为题目 ID）  
**文件**: `src/views/QuestionManagement/ScoringPointManagement.vue`

**功能描述**:
- 展示指定主观题的所有评分细则
- 支持手动新增、编辑、删除评分细则
- 支持一键 AI 生成评分细则（调用 LLM）
- 支持单条/批量审核通过评分细则
- 未审核通过的细则不参与 LLM 评分

**评分细则字段**:
- 得分点描述（必填）
- 该点分值（必填）
- 可接受的同义表达（JSON 数组）
- 排序序号
- 审核状态

**AI 生成流程**:
```
输入题目总分 → 点击"AI 生成"
  → 调用 POST /api/rubricGenerate/{questionId}
  → LLM 返回评分细则列表（is_approved = false）
  → 教师审核每条细则
  → 点击"审核通过"→ is_approved = true
  → 细则生效，参与后续 LLM 评分
```

### 3.7 试卷详情/组卷页（PaperDetailView）

**路径**: `/paperDetailView`  
**文件**: `src/views/PaperManagement/PaperDetailView.vue`

**功能描述**:
- 管理试卷的模块结构（最多 4 个模块）
- 在模块下关联试题（手动选题 / 随机选题）
- 设置每道题的分值
- 拖拽调整模块和试题顺序
- 预览试卷完整内容

**子组件**:
- `LinkQuestionsDrawer.vue`：关联试题抽屉，展示题库供选择
- `QuestionsWarehouseDrawer.vue`：题库选择抽屉

**组卷操作流程**:
```
进入试卷详情页
  → 添加模块（POST /api/paperModule）
  → 在模块下添加试题（POST /api/paperQuestion）
    ├── 手动选题：从题库抽屉中勾选
    └── 随机选题：指定题型和数量
  → 设置每题分值
  → 拖拽排序（PUT /api/paperQuestionsSort）
  → 发布试卷（POST /api/paperPublish）
```

## 六、HTTP 请求封装

### 6.1 Axios 拦截器（request.ts）

**请求拦截器**:
```typescript
// 自动在请求头中添加 JWT Token
axios.interceptors.request.use((config) => {
  const token = getCookie('access_token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

**响应拦截器**:
```typescript
// 统一处理 401 未授权（Token 过期）
axios.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      // 清除 Token，跳转登录页
      clearCookies()
      router.push('/login')
    }
    return Promise.reject(error)
  }
)
```
